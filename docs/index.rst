GovBR Auth
==========

Biblioteca assíncrona FastAPI para autenticação Gov.br com OAuth 2.0, PKCE e
OpenID Connect. O cliente valida ``state``, tokens RS256 por JWKS, ``issuer``,
``audience``, ``nonce`` e o vínculo do ``subject``.
